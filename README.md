# Лабораторная работа — вариант 12

В `main.c` реализованы обе задачи:

- 750 вещественных чисел в диапазоне [100; 110], 10 интервалов, графическая горизонтальная гистограмма (Cairo/X11).
- «Крестики-нолики»: пять подряд на поле 10 × 15; два игрока или человек против компьютера.

## Сборка и запуск

Нужны GCC, make, pkg-config, заголовки и библиотеки Cairo/X11. В текущей среде они установлены.

```sh
make
./histogram
```

Выберите задачу в меню. В игре координаты вводятся как `строка столбец`, начиная с 1. `0 0` завершает игру. Окно гистограммы закрывается крестиком или Escape.

Прямой запуск:

```sh
./histogram --histogram
./histogram --png
./histogram --game
```

`--png` сохраняет `histogram.png` без открытия окна. Параметры варианта заданы константами в начале `main.c`. Файл изображения перезаписывается при следующем построении.

## Контрольные запуски

```sh
make test
./histogram --png --seed 12
./histogram --game < report/game_input.txt
```

Фиксированное начальное значение воспроизводит последовательность в той же реализации стандартной библиотеки. Без `--seed` используется текущее время.

## Отчёт

В папке `report` находятся DOCX, PDF и самодостаточный HTML, скриншоты и текстовые результаты проверок. Заполните поля титульного листа: организация, кафедра, дисциплина, ФИО, группа, преподаватель, город.

`python3 report/build_report.py` пересобирает DOCX и HTML с текущим листингом; исходные контрольные результаты и скриншоты должны соответствовать программе. PDF при изменениях нужно экспортировать заново из DOCX.
