# Задание 2 — вариант 12

Массив `float`, диапазон `[11020; 31702]`. Реализованы вставки, быстрая сортировка с явным стеком и рекурсивная сортировка Хоара.

```sh
cd solution_task2
g++ -O2 -std=c++17 -Wall -Wextra -pedantic task2.cpp -o task2
./task2 --demo
./task2 --test
./task2 --bench
```

`--demo`: исходные 50 чисел и результаты трёх алгоритмов.
`--test`: 327 сравнений с эталонной сортировкой.
`--bench`: реальные измерения для всех пяти размеров из задания; перезаписывает `timings.csv` в текущей папке. Вставки на миллионе случайных элементов выполняются несколько минут.

В отчёте сохранены результаты контрольного запуска. Копирование и проверки не входят в измеряемое время. Измерение каждого алгоритма для каждого размера выполнено один раз.
